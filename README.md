# 基本的なWebサイトテンプレート

このプロジェクトは、HTML, CSS, JavaScriptを用いた最も基本的なWebサイトのテンプレートです。

## ファイル構成

- `index.html`: Webサイトのメインページ
- `css/style.css`: サイト全体のスタイル定義
- `js/main.js`: クライアントサイドのJavaScript
- `images/`: 画像ファイルを格納するディレクトリ
- `.gitignore`: Gitの管理対象外とするファイルを指定
- `README.md`: このプロジェクトの説明

## 始め方

`index.html`をブラウザで開くことで、すぐにサイトの内容を確認できます。
HTML, CSS, JavaScriptを編集して、自由にWebサイトを構築してください。
